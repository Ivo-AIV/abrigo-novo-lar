# Histórico de alterações

## 1.0.0, 03/10/2026

Primeira release deste repositório, baseada nas experiências I a III.

- Tema de alto contraste acessível por teclado.
- Build minificado de HTML, CSS e JavaScript com esbuild.
- Fotografias responsivas em WebP de 480 e 1120 pixels, com JPEG de fallback.
- Verificação de caminhos relativos e importação tardia da tela de projetos.
- Documentação de instalação, manutenção, acessibilidade e limites.
- Integração por pull requests e publicação de dist no GitHub Pages.

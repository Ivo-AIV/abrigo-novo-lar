ABRIGO NOVO LAR: Experiências Práticas I a IV

Projeto acadêmico e ONG fictícia. Fotografias geradas por IA. Nenhum cadastro real.

Instruções completas em README.md.
Requisitos: Node 22 ou superior, npm e servidor HTTP.
Na pasta abrigo-novo-lar: npm ci, npm run build e npm test.
Depois: python -m http.server 8765 --bind 127.0.0.1
Produção: http://127.0.0.1:8765/dist/index.html
Origem: http://127.0.0.1:8765/html/index.html

Site: https://ivo-aiv.github.io/abrigo-novo-lar/
Repositório: https://github.com/Ivo-AIV/abrigo-novo-lar

ACESSIBILIDADE.md registra cobertura e limitações. CONTRIBUTING.md e CHANGELOG.md explicam manutenção e histórico. evidencias/ conserva os registros atuais. dist/ contém somente os recursos publicados.

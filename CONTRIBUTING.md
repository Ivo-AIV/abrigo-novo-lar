# Como contribuir

1. Parta de develop e crie feature/nome-da-mudanca.
2. Faça commits focados, com prefixos como feat, fix, docs ou chore.
3. Execute npm ci, npm run build e npm test.
4. Confira teclado, foco, contraste, layout estreito e dados persistidos.
5. Abra pull request para develop, descrevendo problema, resultado e validação.
6. Revise a release em release/versao; integre na main, marque a tag e sincronize develop.

Hotfixes futuros partem da main e devem retornar também à develop. Nunca inclua credenciais ou dados reais nos exemplos. Preservar a indicação de projeto fictício e a origem das fotografias.
